## A Brief History

This launcher builds packages for **TempGBA4PSP-mod**, which carries a long and
winding lineage. Here's how we got here:

- **2006** — **Exophase** creates
  [**gpSP**](https://github.com/PSP-Archive/gpsp), the first fast GBA emulator
  for PSP
- **2007-2009** — **Takka** forks it into [**gpSP Kai**](https://github.com/PSP-Archive/unofficial-gpSP-kai),
  adding features and polish
- **2010-2012** — The **Supercard Team** ports it to the DSTwo as **NDSGBA**
- **2013** — **Nebuleon** rewrites and
  revives it as [**TempGBA**](https://github.com/PSP-Archive/TempGBA) for the DSTwo,
  mixing gpSP code with a brand new GUI
- **2013-2016** — An anonymous Japanese developer ports TempGBA back to PSP as
  [**TempGBA4PSP**](https://www.axfc.net/u/3063963)
- **2016** — **Phoe-nix** forks it
  into [**TempGBA4PSP-mod**](https://github.com/phoe-nix/TempGBA4PSP-mod),
  cleaning up menus and fixing button mappings
- **2024-2026** — [**andymcca**](https://github.com/andymcca/TempGBA4PSP-mod)
  and [**JxPv2**](https://github.com/JxPv2) continue the fork, adding new features and keeping the emulator alive

This builder tool is a love letter to that lineage. Every bubble it creates
carries a piece of that 20-year history.
