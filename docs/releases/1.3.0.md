# GBA Rush PSP 1.3.0

This release improves runtime diagnostics, menu clarity, configuration safety,
audio lifecycle, and renderer dispatch.

## Changes

- The main menu is grouped by task and each setting has contextual help.
- Long menus scroll without covering the guide or button footer.
- Diagnostics can collect live performance metrics and save a bounded report.
- Renderer selection moves out of the scanline hot path.
- Audio uses a consistent PSP SRC-channel lifecycle across normal play,
  fast-forward, suspend, resume, and shutdown.
- Versioned global and per-game configuration writes retain valid settings and
  recover from interrupted replacement.

## Upgrade

Replace `EBOOT.PBP` and `exception.prx`. Keep the BIOS, ROMs, saves, states,
cheat files, box art, and configuration files.

## Verification

Host, sanitizer, source, and package checks pass with PSPDEV v20260801. The
release candidate was tested with Pokemon FireRed on a physical PSP-2000.
Other PSP models and the wider game benchmark set remain unverified.
