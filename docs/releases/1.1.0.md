# GBA Rush PSP 1.1.0

This release adds two-player GBA link cable emulation over local PSP ad-hoc
Wi-Fi and fixes the suspend and resume lockup found after 1.0.0.

## Highlights

- Normal 8-bit, Normal 32-bit, and Multiplayer 16-bit GBA serial modes.
- Create, join, connection status, peer details, and disconnect controls in all
  five interface languages.
- Versioned packet framing, synchronized transfer barriers, heartbeats,
  timeouts, and clean failure handling.
- Foreground recovery of audio, ROM access, saves, and link state after every
  suspend cycle.
- Finite sound and ad-hoc worker shutdown deadlines.
- Original diagnostic ROM sources and expanded host, sanitizer, malformed
  traffic, timeout, and stress coverage.

## Upgrade

Replace `EBOOT.PBP` and `exception.prx` in `PSP/GAME/GBARushPSP/`. Keep your
existing BIOS, ROMs, saves, states, cheat lists, and configuration files. Back
up save data before updating.

Both PSP systems should run this same emulator build before creating or joining
a link session. Savestates and fast-forward are disabled while that session is
open.

## Compatibility limits

The link implementation is limited to two PSP systems and GBA cable modes. It
does not emulate the GBA Wireless Adapter, UART, General Purpose, JoyBus,
GameCube link, multiboot, or internet relay. Broad compatibility and
performance testing across two physical PSP systems and the commercial game
catalog has not yet been completed.
