# GBA Rush PSP 1.2.0

This release adds adaptive sharp fullscreen output for the PSP display.

## Changes

- `16:9 Auto` starts with two-pass sharp scaling and falls back to nearest
  fullscreen scaling when sustained timing misses are detected.
- `16:9 Sharp` keeps the two-pass path selected manually.
- Fullscreen presentation overlaps PSP GE work with the remaining GBA VBlank
  and avoids redundant framebuffer clears.
- Resume rebuilds transient video state and synchronizes the first frame.
- The FPS overlay reports the active `SHARP` or `CRISP` automatic level.

## Upgrade

Replace `EBOOT.PBP` and `exception.prx`. Keep the BIOS, ROMs, saves, states,
cheat files, and configuration files. Existing installations retain their
saved scale mode; select `16:9 Auto` once to use the new renderer.

## Verification

The adaptive policy passes host and sanitizer tests. The release builds with
PSPDEV v20260801. The new renderer was started successfully on a physical PSP
before publication.
